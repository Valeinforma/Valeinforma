## 🚀 Proyectos destacados

### [ElectronicStore](https://github.com/Valeinforma/ElectronicStore)
E-commerce de componentes electrónicos con API **ASP.NET Core (.NET 10)** y frontend **Next.js 15**. Base de datos en PostgreSQL, autenticación con Firebase y storage con Supabase.

### [Proyecto-Almanaque](https://github.com/Valeinforma/Proyecto-Almanaque) — *TechFix Manager*
Sistema de gestión de servicio técnico: API **ASP.NET Core** consumida por un frontend **Next.js**, con Supabase como backend de datos.

### [StockCarniceria](https://github.com/Valeinforma/StockCarniceria)
Sistema de gestión de stock para carnicería en **.NET**: backend, app **Blazor** web, aplicación de escritorio, app móvil y suite de tests, todo en una misma solución.

### [kioscodb](https://github.com/Valeinforma/kioscodb)
Sistema de gestión de kiosco en **PHP**: ventas, stock, clientes, proveedores, medios de pago y auditoría.

### [Ágora](https://github.com/Valeinforma/Agora)
Plataforma de gestión de capacitaciones desarrollada en **C#/.NET** en el marco de la cursada (en desarrollo).

### [rockenlaciudad](https://rockenlaciudad.vercel.app) 🔗 *demo en vivo*
Sitio web de rock con reproductor de audio, hecho con HTML/CSS/JS y desplegado en **Vercel**.

### [Suplatzigram](https://github.com/Valeinforma/Supabase-Curso) 🔗 *demo en vivo*
Red social estilo Instagram construida con **Next.js + Supabase** (auth, base de datos y storage).
